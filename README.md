# CraftLayer: Digital Agency Website

A responsive 11-page website for a digital studio offering brand identity, web development, UI/UX, AI agents and automation, video editing and social media marketing. Built with plain HTML, CSS and JavaScript, with no frameworks or build step.

**Live demo:** https://craftlayer-website.netlify.app

## Pages

- **Home:** animated service marquee, service cards and a three-stage process section
- **Services:** catalog of all six services with category filters
- **Six service pages:** brand identity, web development, UI/UX, AI agents, video editing, social media marketing
- **Request a project:** brief form that pre-selects the service chosen on the previous page
- **About** and **Contact**

## Features

- Service filtering on the services page
- Project request form with client-side validation and a simulated submission that generates a reference ID (front-end demo, no backend)
- WhatsApp contact button on every page
- Responsive layout for phone, tablet and desktop
- Semantic HTML, keyboard-friendly focus styles and reduced-motion support
- Sample work is clearly labeled as demo concepts

## Tech Stack

- HTML5, CSS and vanilla JavaScript
- Hosting: Netlify

## Run Locally

No installation needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/galaxyshine701/craftlayer-website.git
   ```
2. Open `index.html` in your browser.

## Project Structure

```
index.html, about.html, contact.html, request.html, services.html
service-*.html      six individual service pages
assets/             styles, scripts, images and media
```
